# 着色器接口

`vve:shader` 提供基于 `entity_effect` 粒子的颜色接口，用于把角度映射到渐变色或即时色带。它不是 Minecraft 资源包中的真正 GLSL 着色器，而是 VVE 对粒子颜色参数的轻量封装。

源码目录：`data/vve/function/shader/`。

## 1. 初始化

`vve:shader/init` 由 `vve:_init` 调用，创建并初始化以下临时记分板：

```text
angle、stemp、color
360、256、255、180
linear_base、instant_base
```

其中 `linear_base` 和 `instant_base` 是 Minecraft `entity_effect` 颜色整数的基值。

## 2. 直接绘制接口

### 2.1 `vve:shader/roll_instant`

从 `storage vve:shader color` 读取颜色，并在执行者局部坐标前方生成粒子：

```mcfunction
data modify storage vve:shader color set value -67175413
execute at @s run function vve:shader/roll_instant with storage vve:shader {}
```

宏展开后的命令等价于：

```mcfunction
particle entity_effect{color:<color>} ^ ^ ^
```

### 2.2 `vve:shader/roll_linear`

接口形式与 `roll_instant` 相同，但使用线性色带的颜色值。它同样要求 `storage vve:shader color` 已经存在。

## 3. 按角度绘制

### 3.1 `vve:shader/roll_instant_from_angle`

调用前把目标角度（单位：度）写入 `angle int`：

```mcfunction
scoreboard players set angle int 135
execute at @s run function vve:shader/roll_instant_from_angle
```

函数会：

1. 将角度归一化到 `0..359`；
2. 按 `255 / 360` 计算色带索引；
3. 加上 `instant_base`；
4. 写入 `storage vve:shader color`；
5. 调用 `roll_instant`。

负角度也会先归一化。角度不是整数时，需要由调用者先转换为记分板整数。

### 3.2 `vve:shader/roll_linear_from_angle`

该接口与 `roll_instant_from_angle` 相同，但索引使用 `256 / 360`，基值为 `linear_base`：

```mcfunction
scoreboard players set angle int 270
execute at @s run function vve:shader/roll_linear_from_angle
```

## 4. 测试接口

`vve:shader/test_roll_15` 是固定颜色的测试函数，只生成一个写死颜色值的粒子，不读取 `angle` 或 `storage`。它适合检查粒子是否可见，不适合作为正式颜色接口。

## 5. 使用约束

1. 所有绘制函数都使用当前执行者的局部坐标 `^ ^ ^`。
2. 颜色值必须是 Minecraft `entity_effect` 接受的整数颜色。
3. `angle`、`color` 和 `stemp` 是共享临时对象，不能在同一调用链中嵌套使用。
4. 着色器接口只生成粒子，不修改物理实体状态，也不负责持续调度。
